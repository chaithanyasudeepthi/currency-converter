# 💱 Currency Converter

A simple and responsive currency converter web application that converts currencies using real-time exchange rates.

## 🚀 Features

- Convert between multiple currencies
- Real-time exchange rates
- USD, INR, EUR, GBP, JPY and other currencies
- Source and target currency dropdowns
- Amount validation
- Currency swap option
- Displays conversion rate
- Displays the last updated time
- Popular exchange rates
- API status checking
- Responsive user interface

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript
- Bootstrap

### Backend
- Node.js
- Express.js

### API
- ExchangeRate API
